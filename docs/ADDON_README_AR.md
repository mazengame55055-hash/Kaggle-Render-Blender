# Kaggle Render — إضافة Blender للرندر على Kaggle

رندر مشهدك على GPU بتاع Kaggle من جوه Blender مباشرة، **من غير Discord ولا سيرفر ولا ffmpeg على جهازك**.

**دمج الفيديو بيتم على Kaggle** (الـ ffmpeg هناك). اللي بينزل على جهازك **الفيديو النهائي (mp4) بس**، من غير أي PNG.
لو عايز الإطارات نفسها اختار Output = **PNG frames**.

## التثبيت (Blender 4.2 أو أحدث)
1. `Edit > Preferences > Get Extensions` ← السهم الصغير (⌄) فوق يمين ← **Install from Disk...** ← اختار ملف الـ zip.
2. فعّل **Kaggle Render**.

## إضافة حساب Kaggle
1. من kaggle.com: **Settings > API > Create New Token** (بيدّيك توكين يبدأ بـ `KGAT_`).
2. في Blender: `Preferences > Add-ons > Kaggle Render`، الصق التوكين واضغط **Verify and add**.
   - لو معاك مفتاح قديم (`kaggle.json`) اكتب اسم المستخدم + الـ key.
3. كرر الخطوات لكل حساب عايز تستعمله (يفضّل حسابات تملكها أنت).

## الاستخدام
`Properties > Render` ← لوحة **Kaggle Render**:
1. علّم الحسابات اللي هتشارك. حساب واحد = رندر عادي. حسابين أو أكتر = **تقسيم الفريمات بالتساوي**.
2. اختار **Output**: `Video (mp4)` (الافتراضي) أو `PNG frames`، والـ **Quality** للفيديو.
3. اختار **Save to** (الفولدر) و**File name** (اختياري، الافتراضي اسم الملف) ← الفيديو بيتحفظ `<name>.mp4`.
4. اضغط **Render on Kaggle**. تقدر تكمّل شغل أو تقفل Blender: لما تفتحه تاني الإضافة بتكمل المتابعة لوحدها.
5. لما يخلص، اضغط **Open folder**.

## إزاي الدمج بيشتغل
- **حساب واحد:** Kaggle بيرندر الفريمات ويدمجها في mp4 هناك، وبينزل لك الفيديو النهائي مباشرة.
- **أكتر من حساب:** كل حساب بيدمج الجزء بتاعه في segment صغير على Kaggle، وبعدين kernel صغير (CPU، من غير حصة GPU) بيلصق الأجزاء في فيديو واحد على Kaggle برضه.
  الـ segments بتعدّي مؤقتًا على فولدر شغل الإضافة (مش الفولدر اللي اخترته) وبتتمسح أوتوماتيك، وفي فولدرك بيظهر الفيديو النهائي بس.
- الـ fps بيتاخد من إعدادات المشهد. الصيغة H.264 / yuv420p وبتشتغل في أي مشغّل.

## لو حصلت مشكلة
| اللي حصل | اللي بتعمله الإضافة |
|---|---|
| Blender قفل أو اتهنج أو الجهاز اتطفى | Kaggle بيكمل رندر عادي. افتح Blender تاني والشغل بيكمل لوحده (والحصة بتتحسب وقت الغياب). |
| الكهرباء قطعت وقت حفظ الحالة | بترجّع الحالة من نسخة احتياطية. |
| النت قطع | بتعيد المحاولة أوتوماتيك لحد 10 مرات، ولو فشلت يظهر زر **Retry**. |
| قفلة وقت الرفع أو بعد تشغيل الـ kernel | مفيش حاجة بتترفع أو بتشتغل مرتين. |
| فاتح نافذتين Blender | الأولى بس هي اللي بتتحكم في الشغل. |
| ملف الفيديو المؤقت اتمسح | بيتنزّل تاني من Kaggle. |
| جزء فشل (رفع / kernel / دمج) | الباقي بيكمل، واضغط **Retry** على الفاشل وهيعيد الخطوة دي بس. |
| الرندر اتلغى من Kaggle | بيظهر كفاشل مع زر **Retry**. |
| ملف `jobs.json` تالف أو من نسخة قديمة | الشغل السليم بيتحفظ والعناصر التالفة بتتخطى. |
| الجزء هياخد أكتر من جلسة Kaggle (~9 ساعات) | بتتوقف بدري برسالة تقولك تستخدم كام حساب. |
| Kaggle رفض التوكن / الحصة خلصت / الرقم مش متوثق | بيظهر شرح بسيط مع رسالة Kaggle. |
| فيه فيديو بنفس الاسم | بيتحفظ القديم زي ما هو والجديد باسم `name_2.mp4`. |
| عايز تسيب رندر شغال | زرار **Stop tracking** (Kaggle بيكمل، أوقفه من صفحته لتوفير الحصة). |

## ملاحظات
- بيترفع **نسخة** من الملف المفتوح (ملفك نفسه ما بيتغيّرش). الـ textures الخارجية بتتحزم جوه النسخة (اختياري).
- الرندر بيتم بإعدادات المشهد زي ما هي (engine, samples, resolution). لو المشهد EEVEE ومش شغال على Kaggle فعّل **EEVEE -> Cycles**.
- المشهد لازم يكون فيه Cycles/GPU أو يشتغل على Blender 4.x/5.x (السكريبت بينزّل Blender على Kaggle).
- حصة الـ GPU الأسبوعية بتاعة Kaggle بتتحسب على كل حساب. لإيقاف رندر شغال: افتح رابطه (أيقونة الرابط) واضغط Stop على Kaggle.
- لو جزء فشل: الأجزاء التانية بتكمل عادي، وبيظهر السبب + زر **Retry** (وفي الدمج برضه). اللوج بيتحفظ في `_kaggle_logs` جوه فولدر الحفظ عند الفشل (أو دايمًا في وضع PNG).
- التوكنات بتتخزّن في تفضيلات Blender كنص عادي على جهازك.
- الصوت، والـ textures الـ UDIM/Sequence/Libraries مش مدعومة في النسخة دي.
